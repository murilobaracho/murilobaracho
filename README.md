## 🚀 Projetos em Destaque

### 🔹 [WhatsApp Bot Panel](https://github.com/murilobaracho/bot-wpp-connect)
Bot de automação para WhatsApp desenvolvido em Node.js com WPPConnect e painel web integrado para controle total via navegador — sem necessidade de alterar o código.

- 🌐 **Painel Web Local:** Conecte/desconecte via QR Code direto na página, edite mensagens e faça disparos pelo navegador.
- 📊 **Dashboard Completo:** Métricas de atendimentos automáticos, contatos únicos e gráfico de envios dos últimos 14 dias.
- ⚡ **Resposta Automática:** Atendimento com sistema de *cooldown* (10 min) por contato para evitar disparos repetitivos.
- 📢 **Campanhas em Massa:** Envios para listas CSV com pausas aleatórias para redução de risco de bloqueio.
- 📁 **Gestão de Contatos:** Importação e substituição do arquivo `clientes.csv` direto pelo painel.
- 🤖 **Modo Standalone:** Execução alternativa via terminal focada apenas no atendimento automatizado.

`Node.js` `WPPConnect` `JavaScript` `Automations` `Dashboard`

### 🔹 [FutureCast](https://github.com/murilobaracho/FutureCast)
Rede social inovadora desenvolvida para adolescentes que buscam planejar e moldar seu futuro. Uma plataforma interativa para conectar jovens, compartilhar metas acadêmicas, profissionais e acelerar o desenvolvimento pessoal.

- 🏠 **Feed Interativo:** Espaço principal para compartilhamento de ideias, planos e conexões com foco no futuro.
- 👤 **Perfil Personalizado:** Gerenciamento de dados do usuário, foto de perfil e menu de navegação responsivo.
- 🔒 **Autenticação & Registro:** Telas dedicadas para acesso seguro dos usuários.
- 📚 **Módulos de Desenvolvimento:** Seções integradas focadas em Trabalho (carreira e metas), Vida (hábitos e reflexões) e Família (relações de apoio).
- ✉️ **Suporte & Contato:** Canal direto para comunicação com a equipe da plataforma.

**🔗 [Ver projeto ao vivo](https://murilobaracho.github.io/FutureCast/)**

`HTML` `CSS` `JavaScript` `UI/UX` `Social Platform`
